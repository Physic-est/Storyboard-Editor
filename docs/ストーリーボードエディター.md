# ストーリーボードエディター

## 概要と前提条件
ユーザーが自分で自由に譜面を作成することが出来る音楽ゲームがあります。
その音楽ゲームでは**UIS**という独自のマークアップ言語を使用し、ストーリーボード（譜面に連動するアニメーション背景）を組み込むことも出来ます。
UISを用いたストーリーボードは、多くの場合はプレイ画面の装飾のために、時にはゲームプレイに連動したエフェクトや特殊演出、視覚効果のために使用されます。
ストーリーボードは画像、テキスト、アニメーションフレーム、などあらゆるもので構成することができますが、通常マップをより美しく、ユーザーにとって象徴的なものにするためにデザインされた視覚効果で構成されています。

現在ゲーム内にはストーリーボードのエディターが存在せず、ユーザーが自分で譜面フォルダーに画像等の要素やUISスクリプトを用意し、コーディングする必要があります。
UISの独自仕様を理解する必要があり、コーディングの段階ではプレビューなども見れないため、ストーリーボードを用いた譜面作成は初心者にはかなり敷居の高いものとなっています。
本プロジェクトでは、スクリプトに詳しくない人でも簡単にストーリーボード付き譜面を作成できることを目的として、ストーリーボードエディターを作成します。

## 開発条件
サーバーレスのWebアプリケーションとしてください。
モダンでリッチなUIとし、各要素をドラッグアンドドロップで配置でき、簡単かつ高度にプロパティを設定できること。
PCでの操作を前提とした仕様とすること。
タイムライン機能があり、音源に連動してアニメーションの作成ができること。
タイムラインを動かすと現在の音源の位置に合わせて各要素のプロパティが変動するようにすること（簡易プレビュー）
再生・停止ボタンを設けること。
保存・読み込み機能を設けること。
Undo（Ctrl+Z）・Redo（Ctrl+Y / Ctrl+Shift+Z）機能を設けること。操作履歴は最大100ステップ保持し、プロジェクトの新規作成・読み込み時にリセットされること。
