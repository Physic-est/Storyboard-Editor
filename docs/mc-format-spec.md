# Malody Chart File (.mc) Format Specification — Draft

MalodyのSlideモード譜面ファイルのJSON仕様書。

---

## 概要

`.mc`ファイルはJSON形式で、トップレベルに以下の3つのセクションを持つ。

```
{
  "meta": { ... },
  "time": { ... } or [ ... ],
  "note": [ ... ]
}
```

---

## `meta` セクション

譜面のメタデータ。

| フィールド    | 型      | 説明 |
|-------------|---------|------|
| `id`        | number  | 譜面ID |
| `creator`   | string  | 制作者名 |
| `background`| string  | 背景画像ファイル名 |
| `version`   | string  | 難易度名（例: `"Extend+"`) |
| `preview`   | number  | プレビュー開始位置（ミリ秒） |
| `mode`      | number  | ゲームモード（Key = `1`, Catch = `3`, Pad = `4`, Taiko = `5`, Ring = `6`, Slide = `7`） |
| `aimode`    | string  | AIモード設定（通常は空文字） |
| `song`      | object  | 楽曲情報（下記参照） |
| `mode_ext`  | object  | モード拡張設定（下記参照） |

### `meta.song`

| フィールド | 型      | 説明 |
|----------|---------|------|
| `id`     | number  | 楽曲ID |
| `title`  | string  | 楽曲タイトル |
| `artist` | string  | アーティスト名 |
| `file`   | string  | 音声ファイル名 |
| `bpm`    | number  | 基本BPM |

### `meta.mode_ext`

モード別の拡張設定。

| フィールド    | 型     | 説明 |
|-------------|--------|------|
| `column`    | number | keyモードにおけるカラム数 |
| `bar_begin` | number | 開始小節オフセット |
| `speed`     | number | Catchモードにおけるスクロール速度 |

---

## `time` セクション

BPM・タイミング変化の定義。単一オブジェクトまたは配列で与えられる。

| フィールド | 型       | 説明 |
|----------|----------|------|
| `beat`   | number[] | タイミング変化位置（後述のbeat形式） |
| `bpm`    | number   | このタイミング以降のBPM |
| `delay`  | number   | 遅延（ミリ秒）。譜面開始オフセットとして機能する |

---

## `note` セクション

ノーツの配列。各要素はノーツの種類によって構造が異なる。

### beat 形式（共通）

`beat` は `[小節, 拍, 拍の分割数]` の3要素配列。

```
[measure, beat, division]
```

- `measure`（小節）: 0始まり
- `beat`（拍）: 0始まり
- `division`（分割数）: `beat / division` が小節内の位置

**例:**
- `[1, 0, 4]` → 1小節目の先頭（4分音符基準）
- `[3, 2, 4]` → 3小節目の3拍目（4分音符基準、0始まりなので3拍目は `beat=2`）
- `[9, 0, 288]` → 9小節目の先頭（288分割基準）

### X座標 (`x`)

| 値    | 位置 |
|------|------|
| `-255` | 左端 |
| `0`    | 中央 |
| `255`  | 右端 |

### 幅 (`w`)

最大値 `255`。ノーツの横幅を表す。

---

## ノーツの種類

### 1. 通常ノーツ（タップ）

`type` なし、`seg` なし。

```json
{
  "beat": [3, 0, 4],
  "x": 165,
  "w": 63
}
```

| フィールド | 型       | 必須 | 説明 |
|----------|----------|------|------|
| `beat`   | number[] | ○   | 判定タイミング |
| `x`      | number   | ○   | X座標 |
| `w`      | number   | ○   | 幅 |

---

### 2. スライドノーツ（ロングノーツ）

`type` なし、`seg` あり。`seg` 配列の中に中継点・終点の情報が入る。

```json
{
  "beat": [40, 2, 4],
  "x": 128,
  "w": 70,
  "seg": [
    { "beat": [0, 1, 8], "x": -27 },
    { "beat": [0, 1, 4], "x": -47 },
    { "beat": [1, 0, 1], "x": -82 }
  ]
}
```

| フィールド | 型       | 必須 | 説明 |
|----------|----------|------|------|
| `beat`   | number[] | ○   | 開始タイミング（絶対） |
| `x`      | number   | ○   | 開始X座標 |
| `w`      | number   | ○   | 幅 |
| `seg`    | object[] | ○   | 中継点・終点の配列 |

#### `seg` 要素

| フィールド | 型       | 必須 | 説明 |
|----------|----------|------|------|
| `beat`   | number[] | ○   | 開始点からの**相対**タイミング |
| `x`      | number   | △   | この中継点でのX座標（省略時は変化なし） |

`seg` の最後の要素がスライドの終点となる。`beat` は親ノーツの `beat` からの**相対値**。

---

### 3. Wipeノーツ

`type = 4`。

```json
{
  "beat": [47, 3, 4],
  "type": 4,
  "x": 151,
  "w": 58
}
```

| フィールド | 型       | 必須 | 説明 |
|----------|----------|------|------|
| `beat`   | number[] | ○   | 判定タイミング |
| `type`   | number   | ○   | `4` 固定 |
| `x`      | number   | ○   | X座標 |
| `w`      | number   | ○   | 幅 |

---

### 4. 方向指定ノーツ

`dir` フィールドを持つノーツ。矢印の向きを示す。

```json
{
  "beat": [157, 0, 4],
  "x": 128,
  "w": 64,
  "dir": 8
}
```

| フィールド | 型       | 必須 | 説明 |
|----------|----------|------|------|
| `beat`   | number[] | ○   | 判定タイミング |
| `x`      | number   | ○   | X座標 |
| `w`      | number   | ○   | 幅 |
| `dir`    | number   | ○   | 方向（`2` / `8` を確認済み。詳細要調査） |

---

### 5. 音声トラック定義（type=1）

ゲームプレイ上のノーツではなく、再生する音声ファイルを指定する特殊エントリ。

```json
{
  "beat": [0, 0, 1],
  "type": 1,
  "sound": "1550406328.ogg",
  "offset": 211
}
```

| フィールド | 型       | 必須 | 説明 |
|----------|----------|------|------|
| `beat`   | number[] | ○   | 再生開始タイミング |
| `type`   | number   | ○   | `1` 固定 |
| `sound`  | string   | ○   | 音声ファイル名 |
| `offset` | number   | ○   | 再生オフセット（ミリ秒） |

---

## ノーツ種別の判別フロー

```
noteを受け取る
├─ type == 1  → 音声トラック定義（非ノーツ）
├─ type == 4  → Wipeノーツ
├─ seg あり   → スライドノーツ（typeなし）
├─ dir あり   → 方向指定ノーツ（typeなし）
└─ それ以外   → 通常タップノーツ
```
