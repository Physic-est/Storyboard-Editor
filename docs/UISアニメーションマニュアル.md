# UISアニメーションマニュアル

## 基本記法

- 補間アニメーションの場合
```
:{アニメーション名}
    name={アニメーションの種類}, from={開始時の値}, to={終了時の値}, atime=({開始時間},{終了時間}), trans={イージング値}, repeat={繰り返しの定義}
```

- show / hide の場合（`time` または `atime` を使う）
```
:{アニメーション名}
    name=show, atime={発火時刻(ms)}
    name=hide, time={発火時刻(ms)}
```

## アニメーションの種類について

### 補間アニメーション（`atime` を使う）
|名称|省略形|意味|備考|
|-|-|-|-|
|move|m|座標を移動する|`pos`プロパティと同様、`anchor`ポイントを基準に移動する|
|movex|mx|x座標を移動する|moveと同様|
|movey|my|y座標を移動する|moveと同様|
|size||サイズを変更する|`size`プロパティと同義　`anchor`を基準にサイズが変化する|
|width|w|幅を変更する|sizeと同様|
|height|h|高さを変更する|sizeと同様|
|scale|s|倍率を変更する（sizeとは違う）|`anchor`を中心にして拡大、縮小を行う|
|scalex|sx|x方向の倍率を変更する|scaleと同様|
|scaley|sy|y方向の倍率を変更する|scaleと同様|
|skew||歪ませる|anchorを中心に歪ませる（引っ張る）|
|skewx||x方向に歪ませる|skewと同様|
|skewy||y方向に歪ませる|skewと同様|
|rotate|r|回転させる|`rotate`プロパティと同義。0 ~ 360　anchorを中心に回転する|
|fade|f|透明度を変更する|`opacity`プロパティと同義　0 ~ 100|
|tint||色を変更する|`color`プロパティと同義　カラーコードで指定|

### 瞬間イベント（`time` または `atime` を使う）
|名称|意味|備考|
|-|-|-|
|show|指定時刻に要素を表示する|`from` / `to` / `trans` / `repeat` は使用しない|
|hide|指定時刻に要素を非表示にする|`from` / `to` / `trans` / `repeat` は使用しない|

show / hide は補間を行わない瞬間切り替えである。
同一要素に複数の show / hide を定義した場合、発火済みのイベントのうち最後のものが優先される。

記述例：
```
:mtnElement
    name=hide, atime=0
    name=show, atime=1000
    name=hide, atime=3000
```
（0ms で非表示 → 1000ms で表示 → 3000ms で非表示）

### from/to
- from: 変化前の値
- to: 変化後の値

### time と atime の違い

`time` と `atime` は同じ構文を持つが、動作が異なる。

- **`atime`**: 音楽に追従する。音楽が一時停止するとアニメーションも停止する。UIS アニメーションでは通常 `atime` を使用する。
- **`time`**: 自由に動く。音楽の再生状態に関係なく進み続ける。

### time / atime の構文

`time` と `atime` はどちらも同じ 3 種類の記述方法をサポートしている。

- `atime=1000`
（曲の0秒目から1秒目の間にアニメーションを実行する）

- `atime=(1000,2000)`
（曲の1秒目から2秒目の間にアニメーションを実行する）

- `atime=(1000,+1000)`
（曲の1秒目から1秒かけてアニメーションを実行する）

※終了時刻は開始時刻以下であってはならない。

show / hide で `time` / `atime` を使う場合、発火時刻は開始時刻（単一値の場合はその値そのもの）となる。

### trans
アニメーションに抑揚をつけることができる（だんだん加速させる、減速させる等）
記述例：`trans=(0.24,0.52,0.29,0.97)`

### repeat
定義したアニメーションを繰り返し実行できる
3種類の記述方法がある

- repeat=10
（10回繰り返す）

- repeat=r10
（往復で10回繰り返す）

- repeat=(10,1000)
（10回繰り返し、1回実行するたびに1秒待つ）
